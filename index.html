중고거래 세금 도우미

중고거래·리셀 플랫폼 이용자를 위한 자가진단, 소명자료 준비, 세금 신고 안내

나는 세금 신고 대상일까? 자가진단

쓰던 물건을 파는 일상적 중고거래는 과세 대상이 아닙니다. 다만 영리 목적으로 계속적·반복적으로 판매한 경우 사업자등록 여부와 관계없이 사업소득으로 판단될 수 있습니다. 아래 질문에 답하면 어느 쪽에 가까운지 가늠할 수 있습니다.

1. 주로 어떤 물건을 판매했나요?

2. 산 가격보다 비싸게 판 경우가 있나요?

3. 같은 품목을 여러 개 판매한 적이 있나요? (예: 같은 신발 여러 켤레)

4. 판매 물품 중 미개봉 새 상품의 비중은?

5. 구매 후 얼마 만에 되팔았나요?

6. 연간 판매 규모는? (모든 플랫폼 합산)

소명자료 준비 체크리스트

국세청 안내문을 받았을 때 "개인 물품 처분"임을 소명하기 위한 자료입니다. 미리 준비해두면 좋습니다.

1) 취득 근거 (가장 중요)

  • 온라인 구매: 쇼핑몰·플랫폼 주문내역 캡처 (주문일·상품명·결제금액 표시)
  • 오프라인 구매: 카드 결제내역 (카드사 앱에서 과거 승인내역 조회 가능)
  • 선물·상속 물품: 취득 경위 메모

2) 판매 내역 대장

  • 판매일·플랫폼·품목·판매가·구매일·구매가·판매 사유를 표로 정리 → ② 판매 대장 탭에서 작성하세요
  • "구매가 > 판매가"가 대부분이고 보유기간이 길면, 표 자체가 사업성이 없다는 증거가 됩니다

3) 사용 사실 증빙

  • 실제 사용 중 찍힌 사진 (사진첩·SNS에 자연스럽게 남은 것)
  • "사용감 있음" 등 문구가 포함된 판매글 캡처

4) 돈 흐름 자료

  • 거래대금 입금 계좌·페이 내역 (판매 대장 금액과 대조)
  • 플랫폼 정산내역 캡처 (탈퇴 전 반드시 백업)
자료는 5년간 보관하세요. 세금을 부과할 수 있는 기간(부과제척기간)이 원칙적으로 5년이라, 그 기간 안에는 소명 요구가 올 수 있습니다.
국세청 사칭 피싱 주의 — 문자 속 링크를 누르지 말고, 홈택스(hometax.go.kr) 로그인 후 안내문을 직접 조회하거나 국세상담센터 126으로 확인하세요.

데이터 가져오기

    

      카드사·크림 계정에 직접 연결(API)하는 방식은 로그인 정보를 다뤄야 해서 이 서비스의 원칙(개인정보 외부 전송 없음)과 맞지 않습니다.
      대신 파일 업로드·붙여넣기로 가져오며, 모든 처리는 브라우저 안에서만 이뤄집니다.
    


    

      💳 카드 이용내역 불러오기 — 구매(매입) 증빙 연결
      

        카드사 홈페이지·앱에서 내려받은 이용내역 파일(엑셀 .xlsx 또는 CSV)을 변환 없이 그대로 올리세요.
        이용일·이용금액·가맹점 열을 자동으로 인식합니다 (취소 건은 제외).
        목록에서 해당 구매 건의 [입력]을 누르면 위 입력 폼의 구매일·구매가가 자동으로 채워집니다.
        파일은 브라우저 안에서만 처리되며 어디에도 전송되지 않습니다.
        (파일에 열기 암호가 걸려 있으면 엑셀에서 암호를 푼 뒤 저장해서 올리세요)
      

      
      
      

    


    

      🔖 크림(KREAM) 판매내역 자동 추출 북마클릿 — 한 번에 수집
      

        아래 파란 버튼은 일반 링크가 아니라 실행 코드가 담긴 특수 즐겨찾기(북마클릿)입니다.
        즐겨찾기로 저장해 뒀다가 크림 화면에서 눌러야 동작합니다. 처음 한 번만 설정하면 됩니다.
      

      
    
        
  1. Ctrl + Shift + B를 눌러 주소창 아래에 즐겨찾기 바(가로 줄)를 표시하세요.
    2. 
        
  2. 아래 파란 버튼을 마우스 왼쪽 버튼으로 꾹 누른 채 즐겨찾기 바 위로 끌어다 놓으세요.
          "크림 판매내역 추출" 즐겨찾기가 생깁니다.
    
          드래그가 어려우면: [주소 복사] 클릭 → 즐겨찾기 바 빈 곳에 마우스 오른쪽 클릭 →
          "페이지 추가" → 이름은 아무거나, URL 칸에 붙여넣기(Ctrl+V) → 저장.
    3. 
        
  3. 크림에 로그인해 마이페이지 → 보관 판매 → [종료] 탭을 여세요.
          정산완료가 선택된 상태여야 합니다 (취소·반송 건이 섞이지 않습니다).
          
    이 화면은 목록에 정산금액·정산일이 이미 표시되어 있어, 건별로 상세를 열 필요가 없습니다.
    4. 
        
  4. 즐겨찾기를 한 번 누르면 오른쪽 위에 수집 패널이 뜹니다.
          [전체 자동 수집]을 누르면 첫 페이지부터 마지막 페이지까지 자동으로 넘기며 전부 읽습니다
          (수백 건도 1~2분). 진행 상황이 패널에 표시되고 [중단]으로 멈출 수 있습니다.
          
    자동 클릭 대상은 페이지 번호 버튼뿐이며, 취소·삭제 버튼은 절대 누르지 않습니다.
          수집 중에는 화면을 건드리지 마세요.
    5. 
        
  5. 다 모았으면 [CSV 저장] → 크림판매상세.csv가 저장됩니다.
          이 화면 기준 판매가 칸에는 수수료를 뺀 "정산금액"이 들어가고, 판매사유 칸에 근거와 보관번호가 기록됩니다.
          계좌번호 등 민감정보는 추출하지 않습니다.
    6. 
        
  6. 일반 판매 내역(보관 판매가 아닌 건)은 목록에 금액이 없어, 그 화면에서는
          각 건의 상세를 직접 열기만 하면 알림창 없이 자동으로 누적됩니다 (중복 제외).
    7. 
        
  7. 받은 파일을 아래 "판매 대장 CSV 복원"으로 불러오면 대장에 리셀 행으로 추가됩니다.
    8.

        ← 위 2번 단계에서 끌어다 놓을 버튼 (이 페이지에서 클릭해도 아무 일도 일어나지 않습니다)

        그 경우 아래 "붙여넣기" 방식을 사용하세요.

        인식된 품목·체결일·금액을 확인·수정한 뒤 대장에 추가합니다. 인식이 안 되는 항목은 위 입력 폼으로 직접 추가하세요.

      📎 증빙 사진 일괄 연결 — 파일명의 주문번호로 자동 매칭
      

        영수증·주문 상세 캡처 파일을 한꺼번에 올리면, 파일명에 들어 있는 번호(보관번호 I-…, 판매 주문번호 A-…, 구매 주문번호 B-…)와
        판매 사유 칸의 번호가 같은 대장 행에 자동으로 연결됩니다. 각 행의 📎 버튼으로 사진을 보거나 직접 추가할 수 있습니다.

        파일명이 무신사·웍스아웃·크림구매로 시작하면 매입 사진, 크림판매·보관판매로 시작하면 판매 사진 칸에 들어갑니다.

        ※ 사진은 이 기기의 브라우저에만 저장됩니다(용량 문제로 계정 동기화 대상 아님). 다른 기기에서 보려면 그 기기에서 다시 올리세요.
        원본 파일도 함께 보관하는 것을 권장합니다.
      

      
      
    

  







  

    
리셀 수익이 있었다면 — 신고 안내

    

      되팔 목적으로 사서 반복 판매한 사실이 있다면, 안내문 단계에서 자진 신고하는 것이 가장 유리합니다.
      플랫폼 거래내역은 이미 국세청에 제출되어 있으므로 무시하거나 부인하는 것은 위험합니다.

먼저 진위 확인 — 국세청 사칭 피싱이 매우 많습니다

      
    
        
  1. 문자 속 링크는 절대 누르지 마세요. 국세청은 문자로 앱 설치나 개인정보 입력을 요구하지 않습니다.
    2. 
        
  2. 홈택스(hometax.go.kr)에 직접 주소를 입력해 접속 → 로그인 → My홈택스에서 우편물·안내문를 조회하세요. 진짜 안내문이면 여기에 있습니다.
    3. 
        
  3. 전화가 왔다면 끊고 국세상담센터 126 또는 안내문에 적힌 관할 세무서 대표번호로 다시 걸어 확인하세요.
    4. 
        
  4. "세금 체납으로 계좌가 정지된다", "지금 바로 이체하라"는 식의 압박은 100% 사기입니다.
    5. 
      

    


    

      
종합소득세 신고 안내문 — 고지서가 아닙니다

      
플랫폼 제출 자료를 근거로 "신고 대상인지 확인하라"는 안내이며, 이 단계에서 잘 대응하면 문제가 커지지 않습니다.

      
    
        
  1. 안내문에 적힌 신고·회신 기한부터 확인하세요.
    2. 
        
  2. 내 거래가 어느 쪽인지 판단: ① 자가진단을 해보세요.
    3. 
        
  3. 개인 물품 처분이면 — 세금 낼 것이 없습니다. ② 판매 대장을 정리하고, 아래 소명서 초안 생성기로 회신을 준비하세요.
    4. 
        
  4. 되팔이(리셀) 수익이 있었다면 — 기한 내 신고가 최선입니다. 아래 가산세 계산기로 "지금 신고 vs 미룰 때" 차이를 확인하고, ③ 신고 안내의 절차대로 진행하세요.
    5. 
        
  5. 무시하면 소명 기회 없이 직권 결정(경비 인정 없이 과세)으로 넘어갈 수 있습니다.
    6. 
      

    


    

      
해명(소명)자료 제출 요구 — 기한 내 서면 대응이 핵심

      
    
        
  1. 제출 기한 확인. 기한 연장이 필요하면 담당자에게 미리 연락해 요청할 수 있습니다.
    2. 
        
  2. 담당 조사관에게 전화해 무엇을 소명하라는 것인지 범위를 정확히 확인하세요 (특정 거래인지, 전체인지).
    3. 
        
  3. 개인 물품 처분 거래는: ② 판매 대장 + 취득 증빙(주문내역·카드내역) + 사용 사실 증빙을 묶어 아래 소명서 초안 생성기로 회신서를 작성하세요.
    4. 
        
  4. 리셀 수익 거래가 섞여 있다면 그 부분은 인정하고 신고 의사를 밝히는 게 유리합니다 — 일부를 숨기다 들통나면 부정행위(가산세 40%)로 번질 수 있습니다. 아래 소명서 초안 생성기에서 "리셀 거래 포함" 옵션을 켜면 인정·신고 의사 문단이 자동으로 들어갑니다.
    5. 
        
  5. 금액이 크거나 판단이 어려우면 이 단계에서 세무사를 선임하세요. 회신서 한 장으로 조사 확대 여부가 갈릴 수 있습니다.
    6. 
      

    


    

      
세무조사 사전통지 — 전문가 없이 혼자 대응하지 마세요

      
    
        
  1. 통지서에서 조사 대상 세목·기간·사유를 확인하세요.
    2. 
        
  2. 이 단계는 세무사(또는 세무대리인) 선임을 강력히 권합니다. 조사 입회·의견 진술을 대리할 수 있습니다.
    3. 
        
  3. 사업·질병 등 사유가 있으면 조사 연기 신청이 가능합니다.
    4. 
        
  4. 조사 과정이 부당하다고 느끼면 관할 세무서 납세자보호담당관에게 권리보호를 요청할 수 있습니다.
    5. 
        
  5. 조사 착수 전이라도 스스로 누락분을 수정신고하면 가산세 부담이 줄어들 수 있습니다 — 세무사와 상의해 결정하세요.
    6. 
      

    


    

      
이미 고지서가 나왔다면 — 90일 안에 다퉈야 합니다

      
    
        
  1. 고지 내용이 맞다면: 납부하거나, 일시 납부가 어려우면 납부 기한 연장·분납을 세무서에 신청하세요.
    2. 
        
  2. 고지가 부당하다면: 고지서를 받은 날부터 90일 이내에 이의신청 또는 조세심판원 심판청구를 제기할 수 있습니다 (국세기본법 §61·§68). 90일이 지나면 각하되어 다툴 기회 자체가 사라집니다.
    3. 
        
  3. 불복은 "몰랐다"는 주장만으론 어렵고, 사업성이 없다는 구체적 증빙(② 판매 대장 자료)이 있어야 승산이 있습니다.
    4. 
        
  4. 고지 세액이 크면 불복 전문 세무사·세무법인과 상담하세요. 심판청구는 무료이지만 대리인 조력 여부로 결과가 크게 갈립니다.
    5.
